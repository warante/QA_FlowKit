# Maestro Host E2E Checklist

Record one checklist per verified mobile host.

- Verification date:
- QA FlowKit commit/tag:
- Maestro version:
- Java version:
- Platform: Android emulator / iOS simulator / physical device
- OS and device model:
- Application build identifier:
- `APP_ID` value:
- Flow command:
- Result:
- Evidence link:
- Reviewer:

Do not record credentials, signing material, private download URLs or personal device identifiers.
