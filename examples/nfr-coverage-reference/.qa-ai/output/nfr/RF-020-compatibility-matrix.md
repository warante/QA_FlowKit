# RF-020 browser compatibility matrix

## Scope

Booking summary screen layout and primary actions on latest stable desktop browsers.

## Matrix

| Browser | Version policy | Viewport | Expected behavior                   |
| ------- | -------------- | -------- | ----------------------------------- |
| Chrome  | Latest stable  | 1280x720 | Summary readable; actions reachable |
| Firefox | Latest stable  | 1280x720 | Same as Chrome                      |
| Safari  | Latest stable  | 1280x720 | Same as Chrome                      |
| Edge    | Latest stable  | 1280x720 | Same as Chrome                      |

## Review method

Visual + keyboard smoke on staging. Log blocking defects only; cosmetic deltas go to backlog.

## Evidence owner

QA lead records review outcome in the traceability matrix `Status` column.
