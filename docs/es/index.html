Hecho para equipos QA

Por que QA FlowKit

Los agentes de IA pueden generar pruebas rapido, pero los equipos QA siguen necesitando estructura, trazabilidad, puntos de aprobacion y validacion reproducible. QA FlowKit esta 100% orientado al flujo QA — no es scaffolding de aplicaciones ni prompts genericos de codigo.

1

El problema

Los prompts ad hoc producen Gherkin inconsistente, enlaces RF perdidos y CI sin contrato claro de que significa “terminado” en QA.

2

El enfoque

Un harness QA en el repositorio: fases, aprobaciones explicitas y validadores deterministas — no solo disciplina de prompt.

3

Para flujos QA

Desde el intake de requisitos hasta Gherkin, matriz de trazabilidad, plan de automatizacion y evidencia de release — cada paso tiene salidas definidas.

4

Limites claros

Sin modelo de IA propio, sin telemetria, sin escrituras externas silenciosas. Los artefactos permanecen locales y auditables en el repositorio.

Sin harness QA

  • Prompts puntuales sin orden de fases
  • Archivos .feature inconsistentes y tags faltantes
  • RF y criterios de aceptacion perdidos entre sesiones
  • CI sin quality gate compartido para artefactos QA

Con QA FlowKit

  • /qa-help recomienda el siguiente paso del workflow
  • validate-target ejecuta el quality gate completo del repositorio
  • run start | next | check retoma el trabajo entre sesiones del agente
  • Planes de sync proposal-first — sin escrituras silenciosas en test management

Control desde el repositorio

De requisitos a evidencia de release

La IA razona y edita archivos. QA FlowKit controla el orden de fases, las salidas requeridas, las aprobaciones y los checks de exito o fallo para que el equipo no dependa solo de la disciplina del prompt.

Paso 1 Requisito Intake e ID RF
→
Pasos 2–3 Diseno de pruebas Cobertura y sync plan
→
Paso 4 Gherkin Archivos .feature
→
Paso 6 Trazabilidad Matriz RF → prueba
→
Pasos 7–8 Automatizacion Viabilidad y specs
→
Paso 9 Release gate Evidencia lista para PR

Agente IA

Razona sobre requisitos, redacta Gherkin, propone sync plans y automatizacion — edita archivos en el repo.

Harness QA FlowKit

Valida salidas, bloquea fases invalidas, registra aprobaciones y mantiene estado resumible en .qa-ai/state/.

Los gates clave incluyen confirmacion del ID RF oficial, sync de test management proposal-first y validacion determinista de Gherkin antes de trazabilidad y decisiones de release.

quick — requisitos, Gherkin, trazabilidad standard — diseno completo y plan de automatizacion enterprise — validacion estricta y release gate

Que instala

Un harness QA portable para repositorios objetivo

QA FlowKit anade la carpeta del framework, configuracion del repo objetivo, artefactos generados, features Gherkin y adaptadores opcionales para agentes dentro del repositorio bajo prueba.

Diseno trazable

Valida enlaces RF, IDs duplicados, obligaciones de cobertura y bloques de criterios de aceptacion.

Validadores deterministas

Comprueba idioma Gherkin, tags requeridos, planes de sync, release gates y artefactos QA generados.

Tracks de workflow

Elige quick, standard o enterprise segun la profundidad de gobierno y automatizacion que necesites.

Harness resumible

Estado persistente de ejecucion, event log y run status entre sesiones del agente.

Limites de seguridad

Mantiene las salidas locales, rechaza rutas inseguras, escanea contenido no confiable y evita escrituras externas en el MVP.

Superficie de comandos

Comandos CLI y de agente

Ejecuta setup y validacion desde la terminal. Impulsa el flujo QA desde tu herramienta de IA con comandos slash generados.

En tu terminal

npx qa-flowkit init

Instala .qa-ai/, genera config, carpetas y adaptadores de agente seleccionados.

npx qa-flowkit doctor

Health check de la instalacion del framework y la configuracion del repo objetivo.

npx qa-flowkit help

Recomienda el siguiente paso del workflow QA segun los artefactos actuales.

npx qa-flowkit run start | next | check

Harness resumible con validacion por fase y gates de aprobacion.

npx qa-flowkit validate-target

Ejecuta el quality gate completo del repositorio objetivo (doctor estricto + validadores).

npx qa-flowkit export-report

Exporta casos de prueba alineados con Gherkin a Cucumber JSON, Allure o JUnit XML.

En tu agente IA

/qa-help

Guia contextual — que hacer ahora en el workflow QA.

/qa-init

Inicializacion guiada de QA FlowKit dentro de la sesion del agente.

/qa-add-tests

Anadir pruebas QA para un requisito (RF) nuevo.

/qa-full-flow

Ejecutar el workflow completo guiado de QA FlowKit de principio a fin.

/qa-validate-features

Validar archivos Gherkin de diseno QA contra las reglas del framework.

/qa-gate

Decision de release gate para workflows del track enterprise.
