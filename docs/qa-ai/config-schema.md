# qa-ai.config.yaml schema

Keys generated by `init` from presets in [`.qa-ai/presets/`](../../.qa-ai/presets/). Values shown are typical defaults; presets override paths and tool names.

## Top-level

| Key       | Type   | Description                 |
| --------- | ------ | --------------------------- |
| `version` | number | Config schema version (`1`) |

## `project`

| Key                 | Type                                  | Description                                    |
| ------------------- | ------------------------------------- | ---------------------------------------------- |
| `name`              | string                                | Display name (placeholder until set)           |
| `repoMode`          | string                                | e.g. `qa-design-only`                          |
| `qaTrack`           | `quick` \| `standard` \| `enterprise` | Workflow depth; see [workflow.md](workflow.md) |
| `defaultLanguage`   | `en` \| `es`                          | Legacy default; prefer `interfaceLanguage`     |
| `interfaceLanguage` | `en` \| `es`                          | Language for artifacts and agent questions     |

## `tools`

| Key              | Type   | Description             |
| ---------------- | ------ | ----------------------- |
| `testManagement` | string | e.g. `testrail`, `none` |
| `issueTracker`   | string | e.g. `jira`, `none`     |
| `documentation`  | string | Usually `markdown`      |

## `agents`

| Key              | Type   | Description |
| ---------------- | ------ | ----------- |
| `specialistMode` | string | e.g. `auto` |

## `sources` / `knowledge`

| Key                       | Type    | Description                             |
| ------------------------- | ------- | --------------------------------------- |
| `sources.main`            | string  | Primary requirements source             |
| `sources.analysisPath`    | string  | Optional mixed-source analysis artifact |
| `knowledge.enabled`       | boolean | Load team QA context on init            |
| `knowledge.sourcePath`    | string  | Repo-local context folder               |
| `knowledge.summaryPath`   | string  | Generated summary path                  |
| `knowledge.decisionsPath` | string  | Init decisions artifact                 |

## `requirements`

| Key                                  | Type    | Description                       |
| ------------------------------------ | ------- | --------------------------------- |
| `requireOfficialRfId`                | boolean | Block final Gherkin without RF ID |
| `allowInferredAcceptanceCriteria`    | boolean | Allow inferred CA with approval   |
| `requireApprovalForInferredCriteria` | boolean | User must approve inferred CA     |

## `gherkin`

| Key                          | Type         | Description                                       |
| ---------------------------- | ------------ | ------------------------------------------------- |
| `language`                   | `en` \| `es` | Gherkin language for `.feature` files             |
| `oneScenarioPerFile`         | boolean      | One test case per file                            |
| `requireAcceptanceCriteria`  | boolean      | AC label required in features                     |
| `manualTestsNeedFeatureFile` | boolean      | Manual tests still use `.feature`                 |
| `featurePath`                | string       | Root folder for features (default `features`)     |
| `tags.required`              | string[]     | Required tag names (`priority`, `type`, `manual`) |

## `testrail` (test management block)

| Key                   | Type    | Description                       |
| --------------------- | ------- | --------------------------------- |
| `enabled`             | boolean | Enable TM planning phases         |
| `projectName`         | string  | External project name placeholder |
| `allowCreateSections` | boolean | Policy flags for external writes  |
| `allowCreateCases`    | boolean |                                   |
| `allowUpdateCases`    | string  | e.g. `approval-only`              |
| `allowDeleteCases`    | string  | e.g. `never`                      |
| `mappingFile`         | string  | Local mapping JSON path           |

## `automation`

| Key                                            | Type     | Description                                      |
| ---------------------------------------------- | -------- | ------------------------------------------------ |
| `ui.framework`                                 | string   | e.g. `playwright`, `karate`, `none`              |
| `api.framework`                                | string   | e.g. `playwright`, `karate`, `none`              |
| `mobile.framework`                             | string   | e.g. `maestro`, `appium`, `none`                 |
| `mobile.flowsPath`                             | string   | Mobile flows root                                |
| `mobile.appId`                                 | string   | App identifier placeholder; never a secret       |
| `karate.configPath`                            | string   | Default `tests/karate/karate-config.js`          |
| `karate.mocksPath`                             | string   | Optional mock features root                      |
| `karate.performancePath`                       | string   | Optional Gatling/load assets (non-`.feature`)    |
| `karate.featuresRoots`                         | string[] | Optional override list for Karate validator scan |
| `strategy.automateAllTechnicallyPossible`      | boolean  |                                                  |
| `strategy.requireProposalBeforeImplementation` | boolean  |                                                  |
| `strategy.allowModifyExistingTests`            | string   | e.g. `approval-only`                             |

## `testDesign` / `traceability` / `approval` / `commands`

| Section                                                  | Purpose                                            |
| -------------------------------------------------------- | -------------------------------------------------- |
| `testDesign.systemPath`                                  | System test design artifact                        |
| `testDesign.proposalPath`                                | Per-RF proposal artifact                           |
| `testDesign.coverage.mode`                               | `off`, `advisory` or `strict` coverage validation  |
| `testDesign.coverage.requirePositive`                    | Require positive coverage per RF                   |
| `testDesign.coverage.requireNegative`                    | Require negative coverage per RF                   |
| `testDesign.coverage.requireAlternative`                 | Require an alternative flow or exclusion rationale |
| `testDesign.coverage.requireBoundaryWhenApplicable`      | Require BVA evidence when applicable               |
| `testDesign.coverage.requireAccessibilityWhenApplicable` | Require accessibility evidence or rationale        |
| `testDesign.coverage.requirePerformanceWhenApplicable`   | Require performance evidence or rationale          |
| `testDesign.coverage.requireSecurityReview`              | Require functional security applicability review   |
| `testDesign.coverage.requireTechniqueTraceability`       | Require recorded test-design techniques            |
| `traceability.matrixPath`                                | Traceability matrix                                |
| `approval.*`                                             | Gates before external writes / PR                  |
| `commands.testQA`                                        | Default validate-features command                  |

## Presets

| Preset file                                                                             | Use case                               |
| --------------------------------------------------------------------------------------- | -------------------------------------- |
| [manual-only.yaml](../../.qa-ai/presets/manual-only.yaml)                               | Quick track, no automation frameworks  |
| [playwright-full.yaml](../../.qa-ai/presets/playwright-full.yaml)                       | Default Playwright UI + API automation |
| [maestro-karate-mobile.yaml](../../.qa-ai/presets/maestro-karate-mobile.yaml)           | Maestro mobile + Karate API            |
| [karate-full.yaml](../../.qa-ai/presets/karate-full.yaml)                               | Karate API + UI                        |
| [webdriverio-playwright-api.yaml](../../.qa-ai/presets/webdriverio-playwright-api.yaml) | Legacy beta compatibility              |
| [selenium-jest-browserstack.yaml](../../.qa-ai/presets/selenium-jest-browserstack.yaml) | Alternate stack template               |

Export/import profiles: `npx qa-flowkit config --export` / `--import`.

See [stability-policy.md](stability-policy.md) for what may change during the beta series.
