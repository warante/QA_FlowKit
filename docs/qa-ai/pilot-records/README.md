# Pilot Records

This directory contains only anonymized, publication-approved pilot records.

- Use aliases, never participant or repository names.
- Do not store raw observation notes, prompts, source code, private URLs or personal data here.
- Validate records with `npm run pilots:analyze`.
- A `retrospective-partial` record must state which measurements were unavailable.
- Complete future pilots should begin from
  [`../pilot-templates/pilot-result.template.json`](../pilot-templates/pilot-result.template.json).

Raw notes belong in an access-controlled study location and follow the deletion date recorded during intake.
