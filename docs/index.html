What it installs

A portable QA harness for target repositories

QA FlowKit adds the framework folder, target configuration, generated artifacts, Gherkin features and optional agent adapters directly inside the repository under test.

Traceable test design

Validate RF links, duplicate IDs, coverage obligations and acceptance-criteria blocks.

Deterministic validators

Check Gherkin language, required tags, sync plans, release gates and generated QA artifacts.

Workflow tracks

Choose quick, standard or enterprise depth depending on governance and automation needs.

Safety boundaries

Keep outputs local, reject unsafe paths, scan untrusted content and avoid external writes in the MVP.

Presets

manual-only, playwright-full, maestro-karate-mobile, karate-full, webdriverio-playwright-api and selenium-jest-browserstack.

Adapters

Claude Code, Codex Desktop, OpenCode, Cline, Continue, Aider, Goose, Gemini CLI and generic AGENTS.md instructions.
